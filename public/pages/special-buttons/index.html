Breadcrumbs

You can create breadcrumbs with .breadcrumbs class anb the specifier .arrow or .default to change the style of breadcrumbs.

  • Home
  • Library
  • Data
  • Bootstrap

            <ul class="breadcrumbs default">
                <li><a href="#"><span class="mif-home icon"></span>Home</a></li>
                <li><a href="#">Library</a></li>
                <li><a href="#">Data</a></li>
                <li class="active"><a href="#">Bootstrap</a></li>
            </ul>

Command Button

Create a command button with .command-button class. 


            <button class="command-button alert">
                <span class="icon">
                    <span class="mif-share"></span>
                </span>
                <span class="caption">
                    Share and connect
                    <small>Use this option for home or work</small>
                </span>
            </button>

You can use soft-* and normal-* classes to change button color.

Action Button

You can create an action button with .action-button class. use color classes .soft-*, .normal-*, and accent classes to change button color. 


            <button class="action-button">
                <span class="icon">
                    <span class="mif-share"></span>
                </span>
            </button>

Use class .multi-action to create a multi-action button. You can use modifiers .drop-up, .drop-down, .drop-left, .drop-right for submenu to open it in required direction. 


            <div class="multi-action">
                <button class="action-button rotate-minus bg-red fg-white" onclick="$(this).toggleClass('active')">
                    <span class="icon"><span class="mif-add"></span></span>
                </button>
                <ul class="actions drop-left">
                    <li class="bg-blue"><a href="#"><span class="mif-person_add"></span></a></li>
                    <li class="bg-teal"><a href="#"><span class="mif-library"></span></a></li>
                    <li class="bg-pink"><a href="#"><span class="mif-alarm"></span></a></li>
                    <li class="bg-orange"><a href="#"><span class="mif-lock"></span></a></li>
                </ul>
            </div>

Shortcut

Create a shortcut button with .shortcut class. 


            <button class="shortcut success">
                <span class="badge">10</span>
                <span class="icon"><span class="mif-email"></span></span>
                <span class="caption">Mails</span>
            </button>

You can use soft-* and normal-* classes to change shortcut color.

Toolbar & Tool Button

You can use .toolbar and .tool-button classes to create toolbar.

Use class .outline for button to create outline button.

Add attribute data-caption to add caption to toolbar.

Dropdown Button

Use .dropdown-button class to create dropdown button.

  • Action
  • Another action
  • Something else here
  • Separated link

            <div class="dropdown-button">
                <button class="button dropdown-toggle">Dropdown</button>
                <ul data-role="dropdown" class="d-menu">
                    <li><a href="#">Action</a></li>
                    <li><a href="#">Another action</a></li>
                    <li><a href="#">Something else here</a></li>
                    <li class="divider"></li>
                    <li><a href="#">Separated link</a></li>
                </ul>
            </div>

Transform Button

Use class .transform-button to create transform button. For you available transform classes: .up, .down, .left, .right, .top-left, .bottom-left, .top-right, and .bottom-right.

Click the buttons below to view transform action. 


            <button class="transform-button up"
                onclick="$(this).toggleClass('transform')">
                <span></span>
            </button>
Button Group

Create a button group with Button Group component. You can create a group with radio state or multi state with attribute data-mode="multi". 


            <div data-role="button-group">
                <button class="button square active"><span class="mif-format_align_left"></span></button>
                <button class="button square"><span class="mif-format_align_center"></span></button>
                <button class="button square"><span class="mif-format_align_right"></span></button>
                <button class="button square"><span class="mif-format_align_justify"></span></button>
            </div>
