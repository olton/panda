Progress Bars

Use progress component to create progress bars. To set value use attribute data-value. 


            <div data-role="progress" data-value="25"></div>

To create thin progress bar, add attribute data-small="true". 


            <div data-role="progress" data-value="25" data-small="true"></div>

To change bar color use color classes bg-***, soft-***, or normal-*** and attribute data-cls-bar. 


            <div data-role="progress" data-value="25" data-cls-bar="bg-cyan"></div>
