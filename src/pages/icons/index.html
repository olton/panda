About Icons

Pandora 2.0 uses Metro UI Icons. You can use any icon from this set in your projects. To show an icon, you need to add <span class="mif-***"></span> to your HTML (where *** is icon name). 


            <span class="mif-home"></span>

To change color, use classes fg-*** (where *** is color name). 


            <span class="mif-home fg-red"></span>

You cna use any icon size by adding mif-Nx class (where N is a number from 1 to 10). 


            <span class="mif-home mif-2x"></span>
