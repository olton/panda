Welcome to Panda 1.0

Panda – is a set of templates for building sites of any purpose. This set created with Metro UI, a great component library for building responsive web applications. Set covered almost all the features of the Metro UI library. The template contains different types of reusable and professional responsive components with different variations.

This set is built using only the Metro UI component library, excluding ApexCharts, a great tool for creating various graphs and charts. All charts in Panda were created with ApexCharts.

Set includes:

Common
Brief description and demonstration of common styles and javascript utilities and libraries.
UI Elements
Brief description and demonstration of Metro UI components and widgets.
Demo Pages
Ready to use demo pages.
